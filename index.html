Drag the ⠿ grip to reorder (or use arrow keys on the grip). Star a task before reordering it. Pins set a custom position within starred tasks only. Starred tasks always stay ahead of ordinary tasks; Reset order restores age-based sorting. Completed visible items are retained in the cloud for 90 days, then moved to a local archive on this device when Chronos next opens or checks. Hidden to-dos are excluded from automatic cleanup. Archive entries are not synced. Old completed deadlines follow the same rule; unfinished deadlines are never auto-deleted.
